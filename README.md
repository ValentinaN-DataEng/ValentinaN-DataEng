## 🚀 Featured projects

### Infrastructure Project Financial Analytics
End-to-end analytics for infrastructure project budgets: Databricks SQL validates and transforms raw project and expense records, Delta Lake stores them in a dimensional model (project, contractor and date dimensions; expense and project-performance facts), and a Power BI dashboard covers budget vs. actual, monthly expenditure, budget utilization, contractor allocations and project status.
It is built on sample data, around the questions I've seen project teams ask about cost and schedule.

### 8-Week SQL Challenge
A self-directed SQL Server portfolio: each week is a business case study that goes from profiling and validating the data to written findings. 4 of 8 case studies are complete: customer analytics, NYC 311 service operations, subscription lifecycle and equipment rental growth.
Example from Week 4 (synthetic data for a construction equipment rental company in Colombia): fleet utilization ranged from **84.1%** in Cartagena to **37.1%** in Bucaramanga, which pointed to moving units between branches.
